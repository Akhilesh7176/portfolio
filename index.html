Projects

M.Sc. Thesis

Real-Time 3D Traffic Simulator

Institute of Economics and Transport, TU Dresden

A browser-based microscopic traffic simulator implementing the Intelligent Driver Model. Python/Django REST backend, Three.js/WebGL frontend rendering live vehicle behaviour in 3D. Road networks were built from OpenStreetMap data, and simulated behaviour was calibrated against real drone-captured vehicle trajectories (MiTra dataset, Milan).

PythonDjangoRESTThree.jsWebGLPostgreSQLIntelligent Driver Model
Research project (CMS-PRO)

Fuzzy-Logic Adaptive Genetic Algorithm

Institute of Lightweight Engineering, TU Dresden

A Python optimisation pipeline for generating compliant mechanisms, coupling a genetic algorithm to ANSYS MAPDL simulations in the evaluation loop. A fuzzy-logic controller adapted the search parameters during the run, improving convergence speed by 15% and reducing how often the search settled in local minima.

PythonNumPySciPyANSYS MAPDLGenetic AlgorithmsFuzzy Logic
Research assistant (WHK)

Browser-Based 3D Model Viewer

TU Dresden, under Dr. Martin Erler

A viewer that renders 3D models directly in the browser, with the OBJ and MTL parsing written from scratch so files display without a native client. Built with Three.js and WebGL, with work on load performance for high-resolution models and support for displaying several models at once.

JavaScriptThree.jsWebGLOBJ / MTL parsing
